EPF 電子紙相框 · 韌體安裝

直接從瀏覽器把韌體寫入相框的 ESP32-C6，不需要安裝任何軟體。

需要 Chrome 或 Edge

這個頁面透過 Web Serial 與相框通訊，只有桌面版的 Chrome、Edge 或其他 Chromium 瀏覽器支援；Firefox、Safari 與手機瀏覽器無法使用。

版本

安裝前

  1. 用可傳資料的 USB 線把相框接到這台電腦。只能充電的線不行。
  2. 喚醒相框。它睡著時 USB 埠不存在：短按按鈕可讓它醒約 40 秒；更穩的做法是在開機時長按按鈕約 3 秒進入設定畫面，相框會保持清醒 5 分鐘。
  3. 按下面其中一個安裝按鈕，在瀏覽器跳出的清單中選擇「USB JTAG/serial debug unit」。
  4. 等待完成。寫入約 10 到 30 秒，完成後相框自動重新開機。安裝對話框本身是英文的。

安裝

既有相框

升級韌體

只寫入程式區，Wi-Fi 與伺服器設定會保留。按下後會先問「Erase device」，請不要勾選，直接按 Next。勾了設定就會被清掉。

這個瀏覽器不支援 Web Serial，請改用 Chrome 或 Edge。 這個網址不是 HTTPS，瀏覽器不允許使用序列埠。
全新相框

完整安裝

寫入 bootloader、分割表與程式，並清除所有設定。第一次刷的板子用這個；已在使用的相框刷完要重新設定 Wi-Fi 與伺服器。

這個瀏覽器不支援 Web Serial，請改用 Chrome 或 Edge。 這個網址不是 HTTPS，瀏覽器不允許使用序列埠。

安裝後

升級後

相框會重新開機、連上原本的 Wi-Fi 並取一張新照片，約 40 秒後出現。不需要任何設定。

完整安裝後

  1. 面板會顯示設定畫面，上面有網路名稱、網址與兩個 QR code。
  2. 用手機掃第一個 QR code 加入 ESP32_ePAPER 網路，或手動連線。
  3. 設定頁通常會自動開啟；沒有的話掃第二個 QR code 或瀏覽 http://4.3.2.1。
  4. 填入家裡的 Wi-Fi、密碼與伺服器網址，例如 http://192.168.1.10:15001，儲存。

不用瀏覽器

同樣的檔案也可以用 esptool 或 PlatformIO 寫入。升級只寫 0x10000；完整安裝從 0x0 寫入。

下載 app.bin（升級用，0x10000） · 下載 factory.bin（完整安裝用，0x0） · SHA256SUMS
