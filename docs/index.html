EPF 電子紙相框

韌體安裝

直接從桌面版瀏覽器把韌體寫入相框，不需要安裝任何工具。

  1. 用可傳資料的 USB 線把相框接到這台電腦。
  2. 喚醒相框：短按按鈕可讓它醒約 40 秒；在開機時長按約 3 秒會進入設定畫面並保持清醒 5 分鐘，比較從容。
  3. 按下方的安裝按鈕，在瀏覽器清單中選擇「USB JTAG/serial debug unit」，然後等它完成並自動重新開機。
更新內容

提醒 按下安裝後會先出現「Erase device」的選項，請保持不勾選再按 Next，設定才會保留。
會清除所有使用者設定 完整安裝會抹除整顆 flash，包括已儲存的 Wi-Fi、伺服器網址與重試計數。刷完後相框會進入設定畫面，需要重新連線設定。只有全新或無法開機的板子才需要這個選項。

這個瀏覽器不支援 Web Serial。請在桌面版 Chrome 或 Edge 開啟這個頁面；Firefox、Safari 與手機瀏覽器無法燒錄。

這個頁面不是透過 HTTPS 開啟，瀏覽器不允許使用序列埠。

升級之後

相框會重新開機、連上原本的 Wi-Fi 並取得一張新照片，約 40 秒後出現在面板上。不需要任何設定。

完整安裝之後

  1. 面板會顯示設定畫面，上面有網路名稱、網址與兩個 QR code。
  2. 用手機掃第一個 QR code 加入 ESP32_ePAPER 網路，或手動連線。
  3. 設定頁通常會自動開啟；沒有的話掃第二個 QR code 或瀏覽 http://4.3.2.1。
  4. 填入家裡的 Wi-Fi、密碼與伺服器網址，例如 http://192.168.1.10:15001，儲存即可。
